# 统一开发与测试分支流程

自2026-09-25起，`dev` 是缓存和冷热识别的统一开发、调试及测试分支。
默认工作目录为 `/home/chris/ceph-heat-predictor`。代理约束以根目录 `AGENTS.md` 为准。

## dev

保留缓存模块、HP生产实现，以及Trace采集、离线回放、分析脚本、回归测试和有效开发文档。
所有新的缓存与HP修改、联合测试默认在dev完成，不再分别维护dev和merge两条测试主线。
候选算法需要独立验证，不能将历史实验结果视为当前工作区或线上验收结果。
大型Trace、构建输出和实验原始结果继续放在仓库外的实验目录。

## merge

作为历史整合分支保留，不再承担日常开发、调试和测试。不自动删除其分支或工作区。
本次缓存来源是merge的 `140169f115cb4c0bdcd533f1f1db03891fedbf83`。
旧文档和实验中提到merge，表示当时的来源或运行记录，不改变现在以dev为主的约定。

## main及发布

main继续只保留已经确认的生产实现和稳定文档，不纳入Trace、候选算法及原始实验材料。
生产发布需明确选定内容并通过构建和集成验证，不直接将dev全部内容发布到main。
本次取消“dev始终等于main加一个dev-only汇总提交”的旧约束，不为分支整理重写现有历史。
提交、amend、squash、merge、rebase、tag、push和部署均按当前任务的明确授权执行。
代码及文档默认保持未提交；dev验证通过不等于已更新线上二进制。
